# 可組合的資料目錄

每個區塊綁定固定資料欄位；新增或編輯區塊只讀已同步快照，不呼叫 Google，也不要求新 scope。按「更新最近 28 天」執行基本同步；附加報表按區塊明確更新。目前沒有背景自動排程。

## 已接入

| 資料 | 來源與口徑 | 可用呈現 |
| --- | --- | --- |
| 觀看次數、觀看時間 | 頻道 Analytics；分鐘轉小時 | 數字卡、每日折線／長條 |
| 訂閱淨增、新增、流失 | 頻道 Analytics；淨增為新增減流失 | 數字卡、每日折線／長條 |
| 平均觀看時間 | 原生期間 `averageViewDuration`；不平均每日平均 | 數字卡 |
| 參與觀看次數 | 原生期間 `engagedViews` | 數字卡 |
| 按讚、留言、分享次數 | 每日 Analytics 互動報表；不是影片終身累積值 | 數字卡、每日折線／長條 |
| 已同步影片數 | 已同步、可存取的 uploads metadata 數量 | 數字卡 |
| 流量來源、國家、裝置、訂閱狀態 | Analytics 的固定 dimension 報表 | 水平長條、觀看數／分鐘表格 |
| 搜尋詞、外部與推薦影片來源 | 固定流量明細報表；推薦影片附標題、縮圖與 YouTube 連結 | 長條、表格 |
| 作業系統、播放位置、內容類型、年齡／性別、分享平台、資訊卡、直播同時觀看 | 各報表的固定 dimension／metric 組合，受 API 與頻道資格限制 | 長條、表格 |
| 逐段留存 | 指定已驗證頻道影片的相對位置與留存比率 | 折線、表格 |
| 影片成效 | 影片 metadata 加上影片期間 Analytics | 自選欄位表格 |
| 頻道資訊、資料新鮮度 | 已驗證連線、快照 metadata | 資訊區塊 |

影片表格可選觀看數、觀看小時、訂閱淨增／新增／流失、發布日期、影片長度，最多 5 個資料欄位加標題。可按觀看數、觀看時間、訂閱淨增或發布日期排序，顯示 5／10／20 支；從整份已同步影片目錄排序，不只重排原先前 20 名。

## 限制與缺值

- Google scope 保留 `youtube.readonly` 與 `yt-analytics.readonly`。
- 同步 1–31 個完整太平洋日期，預設最近 28 天。頻道總計獨立查詢，不使用影片加總替代。
- uploads 上限 500 支；超過明確失敗並保留原快照。每次成功同步後有 15 分鐘冷卻。
- 新增的互動與四種分布報表合計 5 個固定查詢，沿用現有每次同步 900 個請求上限、8 分鐘期限及每個請求最多 3 次嘗試。分類查詢取 21 筆判斷是否截斷，最多保存 20 類。
- 分類報表受資料延遲、隱私門檻及省略分類影響。查詢結束日期不是已觀測到的報表水位，也不保證分類加總等於完整頻道數值。
- 個別附加報表失敗可保留核心快照並標示不可用；授權失效或同步預算耗盡則停止並保留先前快照。
- 缺漏日期及 null 不補零。每日互動未覆蓋所有要求日期時，期間互動總計為未知；已知日仍可繪圖。空報表與實際零值分開顯示。
- 原生平均觀看時間與參與觀看數目前只有期間數值，因此不提供每日趨勢選項。
- 影片訂閱是觀看頁歸因，不能加總當作頻道訂閱數；長度不作為 Shorts／長影片分類依據。

收益需要額外 monetary scope 與頻道資格，本版未要求。Studio 即時 48 小時、曝光與 CTR 未接入。附加報表最多保存 32 個查詢結果，各查詢有 60 秒冷卻；不會因新增區塊就自動查 Google。留言區塊目前是互動次數，沒有留言文字或留言者資訊。新版版面不是「所有 YouTube API 欄位」的任意查詢器。

## 自訂與隔離

每個版面最多 16 個區塊，可新增、移除、上移、下移，選四分之一／半寬／滿寬。提供完整總覽、訂閱成長、觀眾洞察、互動表現、精簡數字五個起點。窄螢幕會依可用寬度重排。

服務以使用者與連線複合鍵保存設定。v1 偏好讀入時遷移為 v2，保留原本順序與顯示選項。不接受任意 HTML、CSS、URL、公式、未知指標或多餘欄位；解除連線會一併刪除版面。調整外觀不改 Google 權限。
